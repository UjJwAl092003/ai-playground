Import Coding Exercises from a JSON file

Upload a .json file containing a coding lesson and its exercises. The file will be validated, you will see a preview, and the lesson + exercises are created only after you confirm.

{% csrf_token %}
The file must look like: { "module": "Pandas", "topic": "...", "lesson_slug": "...", "coding_exercises": [ { "exercise_number": 1, ... } ] }
When checked, any exercise_number values in the file are ignored and fresh sequential numbers are assigned starting after the highest existing number for this lesson.

Security: the imported code fields are stored as plain text and are never executed. Only staff users with permission to add questions can use this importer.
