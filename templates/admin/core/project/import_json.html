Import a complete Project from a JSON file

This JSON file is the single source of truth for the project. It contains the project information and its MCQs. The process is: upload → validate → preview → confirm.

The Project is created automatically if it does not already exist. If a Project with the same slug already exists, it is not overwritten — you will only be able to add new questions to it. Existing questions are never overwritten.

{% csrf_token %}
Top-level fields: title, slug, short_description, description, overview, complete_code, output, explanation, learning_outcomes, dataset_info, and questions[].
Each question has: question_number, question_text, option_a–option_d, correct_answer, explanation, python_code (optional), practical_example (optional).
Markdown and fenced ```python code blocks are preserved as-is.
When checked, any question_number values in the file are ignored and fresh sequential numbers are assigned starting after the highest existing number for this project.

Security: the imported python_code is stored as plain text and is never executed. Only staff users with permission to add questions can use this importer.
